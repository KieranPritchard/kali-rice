# kali-rice
Neon-professional XFCE rice for Kali (tested target: UTM).

## Install
    git clone <your-repo-url> ~/kali-rice
    cd ~/kali-rice && ./install.sh

Then log out and back in.

## UTM
- Display device: `virtio-gpu-gl-pci`
- `spice-vdagent` is installed by the script (clipboard + auto-resize)
